# Vendored LemmaScript skills

The `lemmascript*` directories here are copied unchanged from
https://github.com/midspiral/lemmascript-skills at commit
`6e4fc07b3da2ddef5245fa5bd0585b3c391ccd18` ("sync from lemmascript v0.6.12").
Don't edit them in place; to update, copy a newer commit over them, bump
`LSC_VERSION` in `.claude/hooks/session-start.sh` to the matching
lemmascript release, and review the diff. See docs/VERIFICATION.md.
